구글시트 연동

이 페이지는 구글시트를 원본으로 실시간 반영할 수 있습니다. 시트를 게시(CSV)한 뒤, 아래에 링크를 붙여넣어 연결하세요. 연결 정보는 이 브라우저에 저장되어 다음에 열 때도 자동으로 불러옵니다.

🔗 Worki 링크 자동 추출 (API 키 연동) — 추천
이 방식을 쓰면 공지바로가기 컬럼 없이도 Worki 컬럼에 걸어두신 하이퍼링크를 그대로 자동으로 가져옵니다. 매번 URL을 복사-붙여넣기 하실 필요가 없어집니다.
API 키 만드는 법 (한 번만 하면 됨)
1) Google Cloud Console에서 프로젝트 생성 (없다면) → Google Sheets API 검색 후 "사용 설정"
2) 왼쪽 메뉴 API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키
3) 생성된 키를 복사 → 위 입력창에 붙여넣고 "API로 연동하기" 클릭
4) (보안 권장) 키 옆 "제한사항 수정"에서 API 제한을 "Google Sheets API"로, 애플리케이션 제한을 "HTTP 리퍼러"로 걸고 yoonmichoi79.github.io/* 등록

이 키는 브라우저에 저장되며, 시트를 "링크가 있으면 볼 수 있음"으로 공유해두신 상태여야 동작합니다.
(기존 방식) CSV 링크 연동
API 키 없이도 기존처럼 CSV로 연동할 수 있습니다. 다만 이 방식은 Worki 셀의 하이퍼링크를 읽지 못하므로, 링크를 쓰려면 '공지바로가기'처럼 실제 URL 텍스트를 담은 컬럼이 별도로 필요합니다.

1) 구글시트 우측 상단 공유 버튼 → "링크가 있는 모든 사용자"가 뷰어로 보기 가능하도록 설정
2) 브라우저 주소창의 시트 링크(docs.google.com/spreadsheets/d/시트ID/edit...)를 그대로 복사
3) 아래 입력창에 붙여넣고 연결하기 클릭
시트 헤더 형식 (1행)
세그먼트, 대상, 매체, 구분, 프로모션, 시작일, 종료일, 신청기한, 상태, 업데이트, 플래그, 공지바로가기
· 세그먼트: 빅테크 / 버티컬   · 대상: 광고주 / 에이전시
· 상태: 진행중 / 진행예정 / 종료 (시작일·종료일과 오늘 날짜를 비교해 자동 보정되므로 대략적인 값만 입력해도 됩니다)
· 시작일/종료일: M/D 형식 (예: 8/1)   · 신청기한: 날짜 또는 "선착순" 등 텍스트
· 플래그: NEW / UPDATE (없으면 빈 칸)   · 공지바로가기: (CSV 방식일 때만 필요) 프로모션 상세 URL
